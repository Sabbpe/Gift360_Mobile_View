## Mac / Xcode steps (required to finish)

```bash
# 1. Dependencies + web bundle
npm ci
npm run build                 # produces dist/ (webDir)

# 2. Sync the web build into the iOS project
npx cap sync ios              # copies dist -> ios/App/App/public, updates Pods

# 3. CocoaPods
cd ios/App && pod install && cd ../..

# 4. Open the workspace (not the .xcodeproj)
open ios/App/App.xcworkspace
```

In Xcode:
1. **App target → Signing & Capabilities** → select your Team; set the bundle
   identifier to the confirmed id.
2. Confirm **`UpiPlugin.swift` and `BridgeViewController.swift` are members of
   the App target** (they were added to `project.pbxproj`; verify in the
   Project navigator / Build Phases → Compile Sources).
3. Confirm `Info.plist` contains `LSApplicationQueriesSchemes` with
   `tez, phonepe, paytmmp, credpay, bhim` (already added).
4. Run on a **real iPhone** (canOpenURL results are unreliable in the simulator).

### Device verification checklist
1. iPhone with only GPay + PhonePe → sheet shows exactly those two (+ QR).
2. iPhone with no UPI app → "No UPI payment app was found…" + QR + Easebuzz fallback, no dead buttons.
3. Tap an app → that app opens with the same amount/order; pay → return → polling → success → `/orders`.
4. Cancel → pending then FAILED; Retry creates a **new** intent reference.
5. Kill and reopen the app mid-flow → resumes polling for the same order (no new intent).
6. Confirm no `upi://` generic deeplink is ever opened on iOS.
